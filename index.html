Built on guardrails

Three things we don't compromise on.

A grounded answer is only as trustworthy as the system that produced it. These guarantees hold before any query reaches your data.

01

Tenant isolation

Each account lives in its own Postgres schema, scoped per request through search_path. Your tables are never shared with another tenant.

02

Validated execution

Every SQL statement the agent writes goes through an EXPLAIN-based dry-run before it touches the database. Anything that writes, mutates, or steps outside your schema is blocked.

03

Grounded answers

Every number on screen traces back to a row in the file you uploaded. No invented KPIs, no fabricated trends — the narrative is built from what the SQL actually returned.
